# Biome Titles Localization Patch

[![License](https://shields.io/badge/License-GPL--3.0-blue.svg)](LICENSE)

一个为 [Biome Titles](https://steamcommunity.com/sharedfiles/filedetails/?id=2992680615) 提供本地化增强的 tModLoader 模组。

> **注意**：本项目由 AI 辅助编写，介意勿用。

## 功能

- [x] **自动本地化** — 使用 `ModBiome.DisplayName` 显示已翻译的群系名称
- [x] **源模组优先** — 优先读取源模组的本地化文件（支持汉化模组）
- [x] **补充翻译** — 提供 BTitles 缺失的翻译（如 Aether → 以太）
- [x] **自动扫描** — 扫描各模组未收录的 `ModBiome` 并注册到 BTitles（默认关闭）
- [x] **自动配色** — 为新发现的群系自动分配标题颜色和图鉴图标（默认关闭）
